Settings

Display

Drag the mouse to spin the camera 360°, scroll to zoom in or out, double-click the arena to reset the view. Lighting goes from 50% to 200%; double-click to reset to 100%. The night stadium is the default surround. Industrial Pipes is the CC0 Poly Haven map, used as the sky and reflections when checked. The octagon stays open — no cage. Swap the file via ARENA.hdriUrl.

Sound

Double-click a slider to reset to 100%.

Fight

Fight log

Damage is how badly robots dent, lose armor, and break apart. Low is light wear. Medium adds more dents and the odd armor plate. Max bends and dents hard, sheds plates often, and limbs, hands, and the head come off sooner. Loop CPU vs CPU auto-starts the next Bot vs Bot fight and keeps logging. Download fight log saves a JSON file of recent fights (old ones rotate out).

AI API Brain

The key stays in this browser (localStorage) and is sent only to the endpoint above. About two requests a second per API robot; on a timeout, error or invalid reply the last valid action is kept, and a rejected key holds guard. When Learn from fights is on, a short note from recent API fights is sent with the prompt so that robot can improve.

Controls

Keyboard

  • A / D or arrows — sidestep
  • W / S or arrows — in / out
  • J punch · K kick · L block
  • I stomp / ground punch on a downed robot
  • V cycle camera view: arena, fighting, 3rd person, 1st person
  • Esc open or close this panel

Gamepad

  • Left stick or D-pad — move
  • A / × punch · B / ○ kick
  • X / □ or a shoulder button — block
  • Y / △ ground attack (opponent down)
