# HDRI environments

`industrial_pipe_and_valve_01_2k.hdr` is [Industrial Pipe and Valve 01](https://polyhaven.com/a/industrial_pipe_and_valve_01) from [Poly Haven](https://polyhaven.com), CC0 1.0. A night-sky stand-in until a final space/sky pick is chosen. Swap the file with `ARENA.hdriUrl` in `js/config.js`.

Used as `scene.environment` (RGBE/HDR loader + PMREM) and as a dim backdrop when `ARENA.hdri` or the Settings “HDRI environment” toggle is on. Arena lights stay on.
